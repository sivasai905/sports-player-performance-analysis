
# 🏏 IPL Cricket Player Performance Analysis

An interactive dashboard for analyzing IPL cricket player performance using Python, Pandas, NumPy, Plotly, and Streamlit.

## 🚀 Features

- Dashboard overview with key statistics
- Batter performance analysis
- Bowler performance analysis
- Team performance analysis
- Venue analysis
- Interactive data filters
- Dataset explorer
- Download filtered data as CSV

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## 📂 Project Structure

```text
sports-player-performance-analysis/
│
├── app.py
├── ipl_deliveries.zip
├── requirements.txt
└── README.md
```

## 📊 Dataset

The project uses IPL ball-by-ball delivery data.

The dataset is stored in `ipl_deliveries.zip`, which contains
`ipl_deliveries.csv`.

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd sports-player-performance-analysis
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```
